# Práce 001 – Jednoduchá webová stránka

Jednoduchá responzivní webová stránka vytvořená jako řešení zadání **Práce 001**.

## Obsah projektu

- `index.html` – základní HTML struktura stránky
- `style.css` – externí CSS se styly a responzivním layoutem
- `README.md` – dokumentace projektu

## Splnění zadání

Projekt obsahuje všechny požadované prvky:

- [x] veřejný GitHub repozitář lze vytvořit z tohoto projektu
- [x] README s nadpisem
- [x] základní HTML strukturu
- [x] jednoduchý layout vytvořený pomocí CSS Grid
- [x] relativní jednotky (`%`, `rem`, `em`, `fr`, `vw`, `clamp()`)
- [x] minimálně dvě úrovně nadpisů (`h1`, `h2`, `h3`)
- [x] SEO informace (`title` a `meta description`)
- [x] správné a smysluplné názvy souborů
- [x] externí CSS (`style.css`)
- [x] změnu stylu při najetí kurzorem (`:hover`)
- [x] responzivní zobrazení pro menší obrazovky
- [x] sémantické HTML prvky (`header`, `nav`, `main`, `section`, `article`, `footer`)

## Použité technologie

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Spuštění

Stačí otevřít soubor `index.html` v internetovém prohlížeči.

## Nahrání na GitHub

1. Vytvoř na GitHubu nový **veřejný (Public)** repozitář.
2. Nahraj do něj soubory:
   - `index.html`
   - `style.css`
   - `README.md`
3. Pokud chceš stránku zveřejnit jako web, zapni **GitHub Pages** v nastavení repozitáře.
4. Do odevzdání v kurzu vlož odkaz na veřejný GitHub repozitář.
